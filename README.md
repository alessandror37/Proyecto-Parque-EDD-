## Recordatorios importantes sobre Github
- La primera vez que clonen el repositorio, recuerden crear su propia rama y trabajar estrictamente desde esta.
- Recordar previo a cada sesión de codigo que vayan a tener hacer un "pull" para actualizar su codigo al dia.
- Después de cada función o bloque de codigo que realicen, guarden los cambios localmente haciendo commit.
- Cuando hayan terminado y quieran guardar algo al proyecto realizar el "push".
- **Independientemente de este sistema**, si van a realizar un cambio grande, ya sea cambiar el main del proyecto o cambiar algo en los structs avisar previamente al resto.
